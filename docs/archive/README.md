# Documentation & Scripts Archive

**All project documentation and scripts are organized in this archive folder.**

This folder contains all documentation (setup guides, user guides, API docs, etc.) and scripts (essential + testing/legacy) for the Agentic Pipeline project.

---

##  Archive Structure

```
archive/
├── setup/             # Setup and configuration guides
├── guides/            # User guides and features
├── api/               # API documentation
├── testing/           # Test guides and historical results
├── fixes/             # Troubleshooting and bug fixes
├── implementation/    # Implementation plans
├── tracking/          # Development history
├── planning/          # Project planning
└── scripts/           # All scripts (essential + testing/legacy)
    ├── testing/       # Component test scripts
    ├── utilities/     # Helper scripts
    └── aws-legacy/    # Legacy AWS scripts
```
